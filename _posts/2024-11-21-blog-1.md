>제 Github 블로그에서 페이지네이션은 제대로 되나 모든 페이지에 같은 내용이 출력되는 것을 확인했습니다.<br>
>해결 방법 공유하겠습니다!



## home.html 수정

---

근본적인 원인은 home.html에 있습니다. 

아래대로 수정하면 바로 해결 가능합니다. ㅎㅎ

- 수정전

```html
% for post in site.posts %
```

- 수정후

```
% for post in paginator.posts %
```



## _config.yml

---

참고로 한 페이지에 보여주는 항목 수는 _config.yml에서 `paginated` 부분을 수정해주면 됩니다.  

기본 10개로 되있는데 개인적으로 5개가 보기 좋은것 같습니다.

```yaml
paginate: 5
```
